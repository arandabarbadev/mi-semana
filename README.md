# mi-semana

Mi semana: horario, deberes, exámenes y notas — todo en una sola app.

Web: https://arandabarbadev.github.io/mi-semana/

- 🏠 **Hoy**: tu día de un vistazo
- 📅 **Horario**: clases y tardes de L-V + tareas del finde
- 📝 **Deberes**: pendientes y completados con fecha de entrega
- 📚 **Exámenes y entregas**: con cuenta atrás y color de urgencia
- 🧮 **Notas**: asignaturas, medias y objetivos

Tema oscuro, instala como app (PWA) y sincroniza con tu cuenta Google.
